# Local editing polish

2026-10-23. Interface separators use hyphens. Document punctuation, symbols and recovery contents are preserved. Right-click menus expose contextual Paste options, Formatting and Editing groups, retaining existing table/object/review tools. Paste commands use bounded host clipboard inputs and the existing undoable engine operations. Local-only safety settings and file associations are unchanged.

Word: source/merge/plain paste and copy/paste formatting. Tables/Grid: source/destination/values/formulas/formats/transpose, full Paste Special and bounded HTML cell styling from inline declarations and simple local CSS classes. Deck: source/destination/plain/picture paste, rich menu copy, table tools, alignment, distribution and transforms. PDF: selected text markup plus inline cut/copy/paste matching block style and formatting. PDF does not import arbitrary HTML rich clipboard runs in this release.

Public Microsoft Office and LibreOffice documentation is used as a behavioral reference only. No proprietary assets or LibreOffice source code are copied. The release comparison records each checked feature and its assurance limits; complete Office parity is not claimed.
